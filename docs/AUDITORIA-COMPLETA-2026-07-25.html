Roadmap recomendado (impacto × esforço)

1. Fechar IAP nativo (crítico)

  • Em TileBlastBridge.java, passar purchase.getPurchaseToken() para onTileBlastPurchaseSuccess(id, token).
  • Validar ponta a ponta: compra → queueIapConfirm → confirmIapPurchase → reconcile.
  • Impacto na nota geral estimado: +4 a +6 pontos (segurança + monetização + loja).

2. Subir cobertura dos módulos “0%”

  • Prioridade: tb-save, tb-grid, tb-start (init+aliases), depois ads/playbridge.
  • Elevar threshold Vitest gradualmente (25 → 35 → 45).

3. Enxugar boot / meta-ui

  • Extrair registro de actions + fila pós-init do bootApp.
  • Split fino de tb-meta-ui.js (missões vs baús vs XP).

4. Docs de entrada

  • README raiz apontando ARCHITECTURE, sync:www, play-store, functions.
  • Atualizar ECONOMIA-SERVER-SIDE.md após fix do token.
