Pontos fortes × Riscos críticos

✓ Pontos fortes

  • Renderização correta: canvas + rAF + flag de aparelho fraco.
  • Cobertura de features: battle pass, missões diárias/semanais, ranking, conquistas, coleção, ofertas dinâmicas, cofrinho.
  • Testes: 109 testes unit/integração + e2e Puppeteer, suíte verde.
  • Save assinado: anti-cheat retrocompatível e não destrutivo (novo).
  • Conteúdo data-driven: 7 mundos em data/*.json.
  • Pipeline de publicação: Capacitor, AAB, manifest, SW, privacy.

⚠ Riscos críticos

  • Monólito de 4.819 linhas (tb-main.js) + god-module de 1.335 (tb-roadmap.js).
  • Acoplamento global: ~15 window.TB*; ordem das tags <script> é contrato implícito.
  • Legibilidade: minificação manual, nomes de 1–2 letras.
  • XSS: 32 sinks innerHTML; util de escape existe mas 0% adotado.
  • Memória: 65 timers + 77 listeners sem limpeza central.
  • i18n inexistente — bloqueia lançamento mundial.
  • Sem git nesta pasta (rede de segurança frágil).
