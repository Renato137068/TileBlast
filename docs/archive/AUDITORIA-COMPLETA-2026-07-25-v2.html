Roadmap recomendado (próxima onda)

1. Split de tb-meta-ui.js

  • Separar missões / baús / XP / coleção em módulos com init(cfg).
  • Impacto estimado: +1 a +2 em Arquitetura (menos superfície crítica).

2. Cobertura de gameplay / board / modes

  • Unit tests com DOM mínimo + cfg injetado (padrão dos módulos novos).
  • Elevar floor gradualmente: lines 37 → 42 → 48.
  • Impacto estimado: +2 a +3 em Testes.

3. Economia — autoridade server (fase 4)

  • Compra real em conta de licença + reconcile observado.
  • Migrar rankings para write-only Function; endurecer Rules.
  • Retirar grant otimista quando servidor for autoridade total.
  • Impacto estimado: +2 a +4 em Segurança / Monetização / Loja.

4. Hardening de loja

  • Validar AdMob IDs de produção, listing e data safety.
  • Rodar npm run play:prepublish / play:release com secrets reais.
