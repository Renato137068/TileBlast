# Classificação de conteúdo (IARC)

Em **Política do app > Classificação do conteúdo**, responda o questionário. Orientação para Tile Blast:

| Tema | Resposta típica |
|------|-----------------|
| Violência | Nenhuma ou cartoon leve (blocos explodindo) |
| Sexualidade | Nenhuma |
| Linguagem | Nenhuma |
| Drogas | Nenhuma |
| Compras | **Sim** — compras digitais no app |
| Anúncios | **Sim** — anúncios de terceiros |
| Compartilhamento de localização | Não |
| Interação entre usuários | Não (ranking é opcional/nome apenas) |

Resultado esperado: **Livre (Everyone)** ou **10+** dependendo das perguntas sobre compras/anúncios.

## Público-alvo

- **Grupo etário**: selecione faixas amplas; para jogos casuais com anúncios, muitos devs marcam **13+** ou conforme questionário
- **App direcionado a crianças?** Geralmente **Não** (por causa de AdMob personalizado) — confirme com política AdMob Families se quiser público infantil
