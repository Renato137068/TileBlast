# Release builds (AAB)

Coloque aqui o Android App Bundle assinado para upload na Play Console.

Gerado automaticamente por:

```powershell
npm run play:bundle
```

Arquivo esperado: `tileblast-v1.3.1.aab`

**Não commite** arquivos `.aab` se o repositório for público (já está no `.gitignore`).

Upload: Play Console → **Testar e publicar** → **Produção** (ou teste interno) → **Criar nova versão** → Upload do AAB.
