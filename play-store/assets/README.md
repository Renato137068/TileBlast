# Assets da Google Play

Gerados por `npm run play:assets`.

| Arquivo | Uso no console |
|---------|----------------|
| `icon-512.png` | Ícone do app na loja (512×512) |
| `feature-graphic-1024x500.png` | Banner no topo da página (1024×500) |
| `screenshots/phone/*.png` | Capturas de tela — **substitua placeholders** |

## Screenshots reais

Grave no celular ou emulador:

1. Mapa de fases
2. Partida (tabuleiro)
3. Vitória / estrelas
4. Loja ou puzzle diário

**Requisitos:** PNG ou JPEG, proporção 9:16 (ex.: 1080×1920), mínimo 2, máximo 8.

### Como capturar

- **Celular:** Power + Volume baixo (varia por marca)
- **Emulador Android Studio:** ícone câmera na barra lateral
- Renomeie para `phone-01.png`, `phone-02.png`, etc. e apague os `PLACEHOLDER`
